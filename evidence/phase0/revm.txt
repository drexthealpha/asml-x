  What this buys the product: the agent can refuse a cap-breaching batch LOCALLY, for free,
  before signing. The v1 spine run proved the chain refuses a breach; this proves the same
  refusal is predictable off-chain, which is the difference between paying gas to learn no
  and knowing no in advance.

  One limit stated plainly: this simulation deploys a FRESH guard into an empty in-memory
  state and configures it, so it proves the CONTRACT LOGIC reverts as expected. It does not
  simulate against live chain state. Doing that needs a state fork, which is task 7.6, and
  the distinction matters: a pre-flight against the wrong state would authorise what the
  chain refuses.
